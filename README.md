# 🌌 VisionVerse - The Future Awaits - Farewell 2024-2026

A cinematic student portfolio showcase website built for presenting 24 students in a premium interactive gallery experience.

---

## 🚀 Project Overview

VisionVerse is a modern **3D flip-card gallery system** designed to showcase:
- Student profile images
- Individual personal websites
- QR codes for quick access
- Cinematic UI experience

Each card represents a student’s digital identity.

---

## 🎬 Features

✨ Cinematic 3D card flip animation  
🖼️ Image framed poster-style design  
📱 QR code integration for each student  
🌐 Direct link to individual student websites  
🎨 Premium dark UI with gradient glow  
⚡ Fully responsive design (mobile + desktop)  
🚀 Lightweight (pure HTML + CSS + JS)

---

## 📁 Project Structure
>audio
>images
>qr-with-name
>students-pages
>index.html

---

## 🧑‍🎓 How It Works

- Front side → Student image (cinematic card view)
- Back side → QR code + Visit button
- Click button → Opens student personal website

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (3D Transform + Animations)
- JavaScript (Dynamic rendering)
---

## 📌 Setup Instructions

1. Clone or download this repository
2. Keep folder structure same
3. Open `index.html` in browser
